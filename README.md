# pdf2md-project

Convert PDF files to Markdown using [@opendocsg/pdf2md](https://www.npmjs.com/package/@opendocsg/pdf2md).

## Install

```bash
npm install
```

## Usage

```bash
node index.js path/to/file.pdf path/to/output.md
```

Or place a PDF at `input/sample.pdf` and run:

```bash
npm start
```

Output written to `output/<filename>.md` by default.
